Introduction

This Privacy Policy explains how the CXShield mobile application ("the App") handles user information.

Camera Permission

The App may request access to the device camera strictly for the purpose of uploading documents or images as part of the app’s functionality.

Camera access is used only when the user explicitly chooses to upload a document. The App does not access the camera in the background.

Data Usage

Images captured using the camera are processed only to complete the user-requested upload and are not shared with third parties.

Data Security

We take reasonable measures to protect user data and ensure secure handling of uploaded content.

User Consent

By using the App and granting permissions, you consent to this Privacy Policy.
